## Powershell 
### concat into html.ps1
- select multiple files and sort on right side to export a single html
  with each file shown sequentially and with line numbers. 
- intended use case is for aggregating multiple smaller text files in
  order to meet file limits for ai.
- not recursive
### find exe descriptions.ps1
* used to browse files in a directory to view their File Descriptions.
* helpful for skimming through windows exe files
### [/pwsh/unblockgui.ps1](#unblock with gui finder)
* searches recursively for files that are blocked
* unblocks files when you click
